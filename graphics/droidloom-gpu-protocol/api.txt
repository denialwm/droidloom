# Vulkan forwarded to the host GPU. droidloom-gpu-gen reads this list.
#
#   command NAME [sync] [client] [server] [local]
#   struct NAME
#
# `sync` waits for the host even when nothing comes back, so real errors
# reach the application. `client` and `server` mean that side is written by
# hand in its manual.rs; the record frame is still generated. Opcodes follow
# this order. `local` commands never reach the host: the client answers them
# alone (manual.rs) and they get no opcode.
#
# Structures reached from commands are included, and so is every structure
# that may extend an included one, from Vulkan 1.0 to 1.3 and from each
# advertised device extension: chains travel whole. `struct` adds one that
# nothing reaches, such as a hidden extension's.
